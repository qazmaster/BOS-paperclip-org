# BOS Light Rituals

## Daily Pulse

Purpose: keep company execution visible without forcing the human to micromanage.

Inputs:

- new issues;
- issues in progress;
- blocked issues;
- gate failures;
- circuit breaker alerts.

Output:

- short issue/activity summary;
- escalations only when needed.

## Weekly Review

Purpose: review throughput, stuck work, spending, gate failures and strategic drift.

Output:

- improvement actions;
- possible Div7 decisions;
- updated BPI/betting thresholds if needed.

## Batch Approval Ritual

Purpose: reduce cognitive load by approving a batch of shaped work rather than individual microdecisions.

Flow:

1. Div2 scores and blueprints candidates.
2. Betting Table ranks candidates by BPI.
3. Div6 checks cycle capacity.
4. Human/master reviews Pitch Deck.
5. Approve Batch creates Paperclip-native approvals/requests.
