# Import Notes

`bos-company-template.json` is a draft semantic template, not guaranteed to match the latest Paperclip import/export schema.

Before use:

1. Export a sample company from the target Paperclip instance.
2. Compare schema with this template.
3. Map agent profiles to current AGENTS.md conventions.
4. Run C4 and C5 from the spike checklist.
5. Update this directory with the actual importable artifact.
