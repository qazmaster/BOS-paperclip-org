# 7 BOS Division Agents

This directory defines the initial 7 BOS Light division agents as AGENTS.md profiles.

Each agent profile contains:

- identity;
- VFP: Valuable Final Product;
- authority;
- inputs;
- outputs;
- routing rules;
- guardrails;
- escalation rules;
- collaboration expectations.

## Org chart

```text
Div1.Executive / CEO
  ├── Div2.MasterPlanner / Product & Planning
  ├── Div3.Production / Delivery
  ├── Div4.Operations / Reliability & Process
  ├── Div5.Qualifications / QA, Security, Knowledge
  ├── Div6.Resources / Budget & Capacity
  └── Div7.Strategy / Decisions & Adaptation
```

## Minimal routing

- Vague goals -> Div1 then Div2.
- Backlog shaping -> Div2.
- Implementation -> Div3.
- Ops/process incidents -> Div4.
- QA/security/artifact review -> Div5.
- Budget/capacity/resource conflicts -> Div6.
- Ambiguous/complex/chaotic decisions -> Div7.
